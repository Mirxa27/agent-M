# Security Policy

## Supported Versions

We ensure security updates for the following versions of `agent-M`:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.x   | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not open a public issue.** Instead, report the vulnerability privately to allow us to address it responsibly.
2. Send an email to [abdullah@sourcekom.com] with the following details:
   - A description of the vulnerability.
   - Steps to reproduce the vulnerability.
   - Any potential impacts the vulnerability may cause.
3. We will acknowledge your report within 48 hours and work with you to resolve the issue promptly.
